# Изменения

## 1.2.0 — магазин приложений

- **Магазин приложений.** Список на вкладке «Установка» теперь загружается из интернета и пополняется без выпуска новой версии программы. Для каждого приложения автоматически выбирается сборка под процессор телевизора.
- **Список настраивается в программе**: можно добавить свой источник с GitHub, убрать любую запись, вернуть скрытые, подключить собственный репозиторий.
- Список приложений будет расширяться. Если вы хотите добавить своё приложение в магазин — свяжитесь с разработчиком.
- Номер версии теперь указан в имени скачиваемого файла: `UnbrakeTV-1.2.0.exe`.
- Исправлено: из выпусков с несколькими универсальными сборками могла выбираться отладочная (`debug`) вместо обычной.

## 1.1.0

### Новое

- **Сопряжение по коду для «Отладки по Wi-Fi» (Android 11+).** Программа сама выполняет то, что делает `adb pair`: TLS 1.3, обмен ключами SPAKE2 по шестизначному коду и дальнейшую работу по зашифрованному каналу. Телевизоры с «Отладкой по Wi-Fi» находятся в сети через mDNS, порт подключения определяется автоматически.
- **Готовые профили.** Шесть наборов: безопасная очистка для любого ТВ, два профиля для Xiaomi / Mi TV, лишние сервисы Google, сервисы, не работающие в России, демо-режим магазина. Профиль только отмечает приложения — удаление по-прежнему подтверждаете вы. Программа предлагает профиль под марку телевизора.
- **Лёгкий рабочий стол в один клик.** Новая вкладка «Установка»: рабочий стол скачивается со страницы разработчика на GitHub, устанавливается и назначается основным. Список приложений будет расширяться.
- **Установка APK с компьютера** — для приложений, которых нет в магазине телевизора.
- **Демо-режим.** Кнопка на первом экране или ключ `-demo`: встроенный эмулятор телевизора Xiaomi, на котором работают все функции программы. Журнал демо-сеанса не сохраняется, из интернета ничего не скачивается.
- **Проверка обновлений.** При запуске программа узнаёт у GitHub номер последней версии и показывает ссылку на скачивание. Отключается галочкой на первом экране или ключом `-no-update-check`.
- **Автоподключение после перезагрузки.** Программа ждёт, пока телевизор включится, и подключается сама.
- **Закрытие фоновых приложений** одной кнопкой и остановка любого приложения прямо из списка нагрузки.
- **«Результат этого сеанса»** — сколько оперативной памяти и места на накопителе освобождено с момента подключения.
- **Недавние телевизоры** на первом экране — подключение в один клик.
- **Отчёт о ТВ** — список всех пакетов модели одним файлом для пополнения базы знаний.

### Исправлено

- Интерфейс зависал на время долгих команд (очистка кэша, сканирование пакетов): проверка состояния соединения ждала их окончания. «Отключиться» теперь прерывает выполняющуюся команду сразу.
- После отмены диалога опасного удаления кнопка подтверждения оставалась неактивной в следующих диалогах (например, «Перезагрузить»).
- Восстановление приложения считалось успешным по тексту ответа команды; теперь проверяется фактическое состояние пакета на телевизоре.
- Запросы нагрузки накапливались в очереди на медленных телевизорах — новый запрос больше не отправляется, пока не пришёл ответ на предыдущий.
- Отключение во время подключения могло оставить программу «подключённой» к уже ненужному телевизору.
- Список приложений запрашивается явно для основного пользователя (`--user 0`) — так состояние «удалено / установлено» определяется надёжнее на прошивках с несколькими профилями.
- Приложения из магазина с именами вроде `com.google.*` или `com.xiaomi.*` показывались как «Неизвестный компонент» производителя вместо обычного приложения.
- Поиск в сети мог не успеть обойти все сети на компьютерах с VPN, WSL, Docker и виртуальными машинами.
- Температура читалась только с первого датчика; теперь опрашиваются все и показывается самый горячий.
- Процессы вида `com.google.android.gms.persistent` показывались в списке нагрузки отдельными строками.
- Всплывающее сообщение перекрывало кнопку «Удалить выбранные».
- `build.bat` выводил сообщения в неверной кодировке.

### Безопасность

- Интерфейс отвечает только на запросы, адресованные `127.0.0.1` / `localhost` (защита от DNS rebinding), а изменяющие действия принимаются только методом POST.
- Неизвестные компоненты производителя с «говорящими» именами (analytics, telemetry, advert…) теперь попадают в «Рекомендуем удалить» и для известных брендов.
- Рабочий стол скачивается только по HTTPS и только из раздела релизов репозитория разработчика; файл проверяется перед установкой.

## 1.0.0 — первый релиз

- Подключение к Android TV / Google TV по сети без adb.exe: протокол ADB встроен в программу.
- Поиск телевизора в локальной сети с проверкой ответа ADB (VPN и прокси, принимающие любые подключения, не дают ложных устройств).
- Нагрузка в реальном времени: процессор, оперативная память, память устройства, температура, график и список самых тяжёлых приложений.
- Оценка каждого приложения по базе знаний: «Рекомендуем удалить», «Можно», «Осторожно», «Неизвестно», «Критично».
- Защита от дурака: подтверждение для опасных компонентов, слово УДАЛИТЬ для критичных, запрет удалить последний рабочий стол и ядро системы. Все проверки дублируются на сервере.
- Два способа: удалить для пользователя или только отключить.
- Восстановление в один клик, журнал действий.
- Быстрые улучшения: ускорение анимаций, очистка кэша, перезагрузка, выключение отладки.
- Профили: экспорт списка удалённого и импорт на другой телевизор.
